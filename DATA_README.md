# Dataset access

The analysis uses the public credit-card fraud benchmark dataset containing 284,807 transactions and 492 fraudulent transactions.

The raw dataset is not included in this repository because it is a third-party dataset. Users should obtain it directly from the authorized public distribution source and verify its applicable terms of use.

Expected local filename:

`data/creditcard.csv`

The repository contains derived results and code needed to reproduce the manuscript analysis once the authorized dataset is supplied.
